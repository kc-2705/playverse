# Design tokens

Playverse has one dark, game-style look. Colors and fonts are defined once, as CSS variables in `src/styles.css`
and as Ant Design theme tokens in `src/theme.ts`, which both the app and this Storybook use.

## Typography

**Chakra Petch** for game titles and headings:

<Typeset fontFamily="'Chakra Petch', 'Segoe UI', sans-serif" fontWeight={700} fontSizes={[40, 30, 22]} sampleText="ROOFTOP RUNNER" />

**Manrope** for everything else:

<Typeset fontFamily="'Manrope', system-ui, sans-serif" fontSizes={[16, 14, 12]} sampleText="skyline_sam · 48,200 · City Sunset" />

## Shape

- Corner radius: **12px** for cards, buttons and inputs (Ant Design `borderRadius`).
- Buttons use weight 700 so they read clearly over game art.
